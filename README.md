# Christian Mapili Portfolio

Static HTML, CSS and JavaScript website. Open index.html locally or serve this folder with a local static file server. No build step is needed.

Content lives in data.js and index.html. The navy-and-teal theme and responsive layouts live in styles.css. Certificate filters, previews and PDF downloads are handled by script.js.

Public assets contain 16 certificate previews, 16 sanitized certificate PDFs, the résumé, the profile photograph, and two ETDMS screenshots. Certificate PDFs are flattened copies with localized opaque privacy redactions. Private source documents and source archives are excluded.

TESDA records represent five TESDA Online Program course completions. The cybersecurity course remains in progress. Ethical Hacking is a learning interest.
